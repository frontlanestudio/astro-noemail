# Changelog

## 1.0.0 - 2026-04-09

### Changed

- Added SSR response rewriting for on-demand Astro pages via middleware.
- Exported the public `NoEmailOptions` type from the package entrypoint.
- Documented support across static, hybrid, full SSR, and client-only rendering modes.

## 0.1.1 - 2026-04-01

### Changed

- Widened the Astro peer dependency to include Astro v6.
- Confirmed the build-time integration continues to obfuscate email addresses in generated HTML without runtime changes.
- Normalized package ownership metadata to Velohost UK Limited.
- Updated license attribution in the package license files and README.

### Fixed

- Release metadata now reflects version `0.1.1`.

## 0.1.0 - 2026-04-01

### Added

- Initial release of `astro-noemail`.
